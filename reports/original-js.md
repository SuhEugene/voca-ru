# original: русский фронтенд для tiny-voca в JS

Ветка `original`, worktree `worktrees/original`. Всё ниже — работа только в
`js/` этого дерева. `main`/`master` не трогались.

## Что сделано

### 1. Страница (`js/index.html`)

- Модель по умолчанию:
  `https://huggingface.co/SuhEugene/voca-ru/resolve/main/gguf/voca-ru-js.gguf`
  (23,5 МБ). `?file=` и `?script=` работают как раньше.
- Интерфейс по-русски: заголовок, подсказка, кнопки, лог, сообщения об
  ошибках. Голос по умолчанию — `F2` (женский), второй — `M2`.
- Импортирует `js/ru/index.js` вместо `js/dizione/engine.js`.
- «Измерить скорость» теперь меряет текущий русский текст, а не английский
  `test/sentences.json` (его id относились к английской модели).
- Разбиение на предложения (`js/text.js`) понимает заглавные кириллические
  буквы и цифры после `[.!?…]`, добавлены русские сокращения (`т. д.`,
  `ул.`, `стр.`, `г.`, …), чтобы не рвать фразу после них.

### 2. Русский фронтенд (`js/ru/`)

Чистые ES-модули, без сборки, npm и сети. Данные — только из загруженного
GGUF (`config.json`, `phonemizer/stress_dict.tsv`,
`phonemizer/g2p_lexicon.tsv`).

| файл | что делает |
|---|---|
| `numbers.js` | количественные и порядковые числительные, падежи, род, десятичные — порт `training/voca_ru/text/numbers.py` |
| `normalize.js` | числа, даты, время, деньги, проценты, ординалы, единицы, сокращения, латиница, «ё», пунктуация — порт `normalize.py`; `\b` заменён на Unicode-границу, потому что JS `\b` не считает кириллицу словом |
| `stress.js` | словарь `word<TAB>сло́во` + правило-фолбэк; марка U+0301, в модель уходит 0/1 |
| `g2p.js` | лексикон `слово<TAB>телефоны`, правила для OOV, токенизация `<bos>/<sp>/паузы/<eos>`; id из `config.vocab` |
| `index.js` | `fromGGUF(file)`, `analyze(text)` с теми же полями, что Python, и `phonemize(text)` для `js/text.js` |

Паритет с Python-эталоном: `plain_text` — 380/380 предложений; `stressed_text`
— 369/380 (расхождения только на OOV-словах, где у Python работает
RUAccent/ONNX-модель ударения, а в GGUF её нет).

### 3. Тесты

- `js/ru/test/parity.mjs` — сравнение с фикстурой Python.
- `js/ru/test/fixtures/parity.json` — 380 предложений (350 из
  `data/scripts-ru/batch1.jsonl` + `batch2.jsonl`, детерминированная выборка,
  и 30 синтетических: числа, даты, деньги, «ё», пунктуация). 247 КБ.
- `js/ru/test/make_fixture.py` — пересборка фикстуры через Python-эталон.
- `js/ru/test/page-smoke.mjs` — headless-проверка логики страницы: GGUF →
  разбиение на 4 предложения → фонемы → синтез `F2`, проверки длины и
  конечности сэмплов.

### 4. Документация

`js/README.md` переписан по-русски: страница, модель по умолчанию, устройство
`js/ru/`, паритет, CLI, ограничения. Разделы про сам движок `tiny-voca.js` и
`pack.mjs` сохранены (помечены как upstream/английские). `dizione/` явно
помечен как английский и неиспользуемый страницей.

`js/say.mjs` переведён на русский фронтенд, по умолчанию тянет русский GGUF,
`--file`, `--voice`, `--output` работают.

## Цифры паритета (точные)

`node js/ru/test/parity.mjs`, фикстура из 380 предложений:

| выборка | предложений | id совпали | id и ударение совпали |
|---|---|---|---|
| все | 380 | 368 (96,84 %) | 366 (96,32 %) |
| все слова в обоих словарях GGUF | 155 | **155 (100,00 %)** | **155 (100,00 %)** |
| есть OOV-слова | 225 | 213 (94,67 %) | 211 (93,78 %) |

Дополнительно измерено отдельным прогоном (в `parity.mjs` не печатается):
`normalize()` совпадает с Python на 380/380, `stressed()` — на 369/380.

Все 14 оставшихся расхождений — предложения с OOV-словами: у Python для них
есть 3,19 млн форм RUAccent, omographs/yo_words и ONNX-акцент, у JS — только
100 тыс. форм из GGUF и правило-фолбэк. Два расхождения по ударению — слова
с «ё» (`партнёрские`, `премьер`), которые Python восстанавливает из
`yo_words`, а в GGUF их нет.

## Как воспроизвести

Страница:

```
cd js && python3 -m http.server 8000
# http://localhost:8000
# локальный файл: http://localhost:8000/?file=../out/voca-ru-js.gguf
```

Headless-проверка страницы (нужен GGUF; по умолчанию
`/Users/suheugene/projects/22-tiniest-voca-ru/out/voca-ru-js.gguf`):

```
cd worktrees/original
node js/ru/test/page-smoke.mjs
```

Паритет:

```
cd /Users/suheugene/projects/22-tiniest-voca-ru
. scripts/cache-env.sh
VOCA_CACHE=$PWD/.cache .cache/venvs/r4/bin/python \
    worktrees/original/js/ru/test/make_fixture.py   # хэш фикстуры воспроизводится
cd worktrees/original
node js/ru/test/parity.mjs
```

CLI:

```
node js/say.mjs "Привет! Это voca-ru." --voice F2 --output /tmp/out.wav \
  --file /Users/suheugene/projects/22-tiniest-voca-ru/out/voca-ru-js.gguf
# 2,46 с аудио за 0,25 с, 9,7x реального времени
```

## Что не проверено

- Реальный браузер: проверен только синтаксис модульного скрипта
  (`node --check`) и вся его логика в Node. `AudioContext`, воспроизведение,
  `?file=` через HTTP и скачивание с Hugging Face вживую не запускались.
- Bun не запускался; `say.mjs` проверен только на Node 26.
- Качество звука на слух не оценивалось; проверены длины, конечность сэмплов
  и соответствие id/ударений Python.
- `dizione/` и его старые тесты (`js/test/*`) не запускались: для них нужны
  внешние данные dizione, которых нет в репозитории. Они не затронуты и
  страницей не используются.
- Q8_0-путь (`pack.mjs`) не проверялся: русский GGUF — float32.

## Замечания по данным

- В `phonemizer/stress_dict.tsv` 13 из 100 000 ключей начинаются с латинской
  `c` вместо кириллической `с` (например `cила`). Это дефект генерации
  словаря, а не JS: такие слова просто попадают в фолбэк. Для сравнения,
  в Python-словаре они корректны; на паритет это влияет только как OOV.
- `g2p_lexicon.tsv` не содержит английских букв и покрывает 14 492 слова;
  этого достаточно для 155/380 предложений выборки без OOV.
